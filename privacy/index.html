Privacy

Your data stays yours.

A plain-language statement about the browser and about this website.

This website

  • No cookies, no analytics, no advertising or tracking scripts, and no third-party fonts.
  • The only thing remembered is your light/dark choice, stored in your own browser and never sent anywhere.
  • Downloads are served from GitHub Releases, so GitHub sees the request as it would for any file it hosts.
  • The optional download-statistics page asks GitHub’s public API for release download counts when you open it. It sends nothing about you.

Prism Browser

  • History, bookmarks, passwords and settings are stored locally on your computer.
  • Prism contains no analytics or tracking SDK.
  • Prism makes background requests only to refresh its filter lists, to check for a newer version, and, when DNS-over-HTTPS is enabled, to the DNS provider you chose (Cloudflare by default). Both checks can be switched off in Settings.
  • The update check downloads one small public file (latest.json) from the project’s GitHub release at start and then once a day. It sends no identifier, cookie or information about you or your PC. GitHub keeps a count of how many times that file was downloaded, which gives the author a rough, anonymous idea of how often Prism is used, and nothing more.
  • The password vault is encrypted with AES-256-GCM using a key derived from your master password; it never leaves your PC.
  • The optional VPN and proxy features send only browser traffic, and only to the server or provider you configure.
