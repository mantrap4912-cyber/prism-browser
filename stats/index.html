    Reading these numbers honestly

    • GitHub counts every download request for the file, including repeat downloads, re-installs on another PC, and some automated scanners. It is an upper bound on installs, not a count of people.
    • Prism has no analytics or user IDs. The only usage signal is the update check: each start (and each day it stays open) downloads a tiny public file, and GitHub counts those downloads. It is a rough activity figure, not a head-count: one person who launches Prism five times counts five times, and people who switched the check off aren’t counted.
    • Counts only include downloads made from the GitHub release. Copies shared by email, USB sticks or other sites aren’t seen.
