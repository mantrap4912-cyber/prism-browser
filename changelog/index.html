Changelog

What changed in each version of Prism Browser, newest first.

0.1.6

2026-10-26Latest
Faster, lighter, and your extensions just work
  • Much lighter: a custom new-tab photo is now kept as a small file instead of inside the settings, which were re-sent to every window on each change. On a real profile the Prism process went from 388 MB to 122 MB and the ad-block rules load in about a second instead of up to 22.
  • Tabs you just used stay ready: the memory saver only tightens up under real memory pressure, and the tab you came from is never put to sleep, so switching back is instant.
  • localhost and local dev servers open, including ones that only listen on IPv6, LAN names, the Windows hosts file and 0.0.0.0 addresses.
  • Links opened from other apps no longer fail with “The requested resource is in use” after an unclean exit.
  • “Add to Prism” on Chrome Web Store and Edge Add-ons pages installs the extension directly.
  • McAfee WebAdvisor (and other extensions that talk to a desktop app) now connect to their app.
  • An ad blocker on/off switch on the new tab page, next to the VPN one.

0.1.5

2026-10-17
Your Chrome extensions, site apps and an AI side panel
  • Extensions switched on in Google Chrome are added to Prism automatically, with a puzzle button next to the address bar for their popups and options.
  • Install any site as an app with its own window and Start menu shortcut.
  • An AI assistant panel (Gemini, Claude or ChatGPT) opens beside your page on the provider’s own website, where you sign in with your own account.
  • Pop-ups, “Leave site?” prompts and downloads all use Prism’s own interface.
  • Prism can be set as your default browser and opens .html, .pdf and .svg files from Explorer.
  • New tab shortcuts are yours to add, edit and remove.

0.1.4

2026-10-16
Prism Dash, an offline game
  • Prism Dash: a rhythm runner that works with no internet. 24 levels in 6 worlds, a level editor, a garage, daily challenges and achievements. Open it from the “No internet” page or type prism://dash.
  • Chrome extensions (since 0.1.3): add one from a Chrome Web Store link, an unpacked folder or Chrome, Edge and Brave.

0.1.3

2026-10-10
Knows when there’s a new version
  • Update check: at start and then daily, Prism looks for a newer version by downloading one small public file from GitHub, with no ID and nothing about you. Switch it off in Settings → System → Check for updates.
  • A toast with a “Get it” button appears when a newer version is available.

0.1.2

2026-10-09
Make it yours
  • New tab personalisation: choose a built-in background or your own photo, with fit, dim and blur controls.
  • Cookie banners are rejected automatically (“Reject all” / “Only necessary”), even when the ad blocker is off.
  • Better offline handling: Prism checks that you are really offline and reloads the page for you when you reconnect.
  • A clearer “Can’t reach this page” screen with a retry and a back button.
  • Improvements to the download manager and the right-click menus.

0.1.1

2026-10-06
Honest labels
  • The VPN feature is now clearly labelled Beta throughout the interface.

0.1.0

2026-10-03
First light
  • Windows 11-style shell with a vertical tab rail, workspaces and containers.
  • Ad and tracker blocking with 11 lists and about 257,000 rules, plus a YouTube ad guard.
  • Encrypted password vault with a password generator.
  • WireGuard and proxy support for browser traffic.
  • Installer with per-user install, Start menu entry and no admin prompt.
